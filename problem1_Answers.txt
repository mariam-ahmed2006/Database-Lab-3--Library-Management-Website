Q1.3 - Both mgr_ssn and Dno are NOT NULL

Answer:
There is a circular dependency. An employee needs an
existing department, and a department needs an existing
employee as manager. We can allow mgr_ssn to be NULL
initially, insert the records, and then update the manager.
MySQL does not support deferred foreign-key checking.
